# FLYFORMER LAB — 3D 초파리 AI 교실

학교 3D 교실의 칠판 문제를 책상에 앉은 초파리가 푸는 인터랙티브 교육용 웹 시뮬레이터입니다.

## 핵심 기능

- 3D 교실: 칠판, 책상/의자, 초파리 세 마리, 마우스 드래그 카메라 회전
- GPT 모드: 앞 단어들만 이용해 다음 토큰 후보 예측
- BERT 모드: `[MASK]` 앞뒤 단어들을 함께 참고해 단어 후보 예측
- **7단계 계산 과정:** 토큰화 → 임베딩 → Q/K/V → 어텐션 점수·Softmax → 문맥 벡터 → 로짓·확률 → SGD 학습
- 단계별 실제 수치: 토큰 배열, 12차원 벡터 일부, Q/K/V, 각 토큰의 어텐션 확률, 문맥값, 후보 로짓, 학습 손실/기울기
- +1/+10/+100/+1000 SGD 학습 버튼, 등록된 학습 문제 정확도 및 변화 그래프
- **직접 출제:** 사용자가 문제와 정답을 입력하면 정답을 포함한 3개 후보로 분류하고 실제 정답 레이블을 기준으로 가중치 훈련

## 직접 입력한 문장의 정답은 어떻게 알까요?

초파리는 사용자가 입력한 문장의 정답을 **처음부터 알지 못합니다**. 사용자는 답을 채점 및 감독학습에 쓰도록 등록합니다. 정답은 모델 추론 중 정답 여부 판단에 사용되지 않으며, 후보 목록에는 포함됩니다. 소형 분류기가 단어의 확률을 계산하고 최댓값을 선택합니다. 학습 버튼으로 교차엔트로피 SGD를 실행하면 사용자가 등록한 문장도 훈련 세트에 포함됩니다.

**중요:** 이 시뮬레이터는 실제 GPT/BERT 모델의 자연어 이해력을 제공하지 않습니다. 띄어쓰기 기반 토큰화, 고정 해시 임베딩, 고정 Q/K/V, 학습 가능한 **출력층**으로 핵심 아이디어를 단순화했습니다. 정답이 후보 세 개 안에 들어있다고 해서 일반 문장에 대한 열린 어휘 생성이 가능한 것은 아닙니다. 표시한 정확도는 **훈련 데이터 정확도**이며 일반화 성능이 아닙니다.

## 기술 및 실행

- 외부 React 의존성 없이 작성한 정적 HTML+CSS+JS
- Three.js 0.180.0 ESM CDN (`https://esm.sh/three@0.180.0`)과 WebGL 사용: 인터넷/브라우저 그래픽 지원 필요
- 테스트: 소형 모델의 예측 확률 합계, 어텐션 합계, SGD 100회 후 정확도 개선, 사용자 정답 추가 학습 확인
- Vercel 정적 웹 배포, 별도 API 키 또는 서버 불필요

## 발표용 시연 추천

1. 기본 GPT 문제에서 학습 전 예측.
2. ①~⑥ 계산 단계에서 실제 숫자와 인과 마스크 확인.
3. +100회 학습 후 같은 문제 재예측.
4. BERT로 전환해 앞뒤 문맥 활용 확인.
5. 직접 문제와 정답을 등록한 뒤 학습 전후 결과 비교.
